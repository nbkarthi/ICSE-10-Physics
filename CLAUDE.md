# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project purpose

Interactive learning artifacts for Class 10 ICSE Physics (simulations, visual explainers, practice tools). The audience is ICSE Grade 10 students, so content should follow the ICSE Class 10 Physics syllabus (e.g. Force, Work/Energy/Power, Machines, Refraction, Lenses, Spectrum, Sound, Current Electricity, Household Circuits, Electromagnetism, Calorimetry, Radioactivity).

## Current state

The repository is newly initialised: it contains only `README.md`. There is no build system, package manager, linter or test suite yet, so there are no build/lint/test commands to document. Update this file when tooling and a directory layout are established (including how to run a single test, if tests are added).

## Conventions

- Interactive pages are published with the Artifact tool, which requires a self-contained HTML file. Keep each interactive as one HTML file unless it needs supporting files.
- Physics must be correct and use ICSE-style notation, SI units and formulae as taught at this level. Check numeric examples.
